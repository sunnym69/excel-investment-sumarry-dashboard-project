# excel-investment-sumarry-dashboard-project
📊 Investment Preference Analysis – Excel Analytics Project
📁 Project Overview

This project analyzes how individuals choose between various investment avenues such as Mutual Funds, Equity Market, Fixed Deposits, PPF, Gold, and others.
The dataset captures responses about investment preferences, objectives, sources of influence, and demographic details.

The goal was to identify patterns, correlations, and insights from investor behavior using Excel.

🎯 Objective

To understand:

Which investment avenues are most preferred overall

How gender, objectives, and sources of influence affect investment choices

Relationships between different avenues (e.g., Mutual Funds vs Equity, FD vs Gold)

How investors monitor and expect returns from their chosen avenues

📂 Dataset Description
Column Name	Description
Gender	Respondent gender
Age	Age group of respondent
Investment_Avenues	Type of investment options evaluated
Mutual_Funds, Equity_Market, Debentures, Govt_Bonds, FD, PPF, Gold	Rating (1–7 scale) of preference for each avenue
Factor	Key factors influencing investment (e.g., risk, returns, liquidity)
Objective	Main financial goal (saving, income, growth, etc.)
Purpose	Reason or motivation for investing
Duration	Duration of investment (short/medium/long term)
Monitor	How frequently investors monitor investments
Expect	Expected return type (high risk/high return vs stable returns)
Source	Source of investment advice (friends, internet, consultants, etc.)
📈 Analysis Performed

Demographic Insights

Gender-based and age-based preferences across all investment avenues.

Objective Analysis

How financial goals (savings, growth, income) influence chosen avenues.

Source Influence

Which source of advice drives higher preference for certain investment types.

Correlation Matrix

Relationship between investment avenues to identify complementary or substitute preferences.

Investment Duration Patterns

Which avenues attract long-term vs short-term investors.

Heatmaps & Charts

Used conditional formatting and pivot charts for visual storytelling.

🧠 Key Insights

Investors favor Mutual Funds and Equity Markets for growth objectives.

Fixed Deposits and Gold dominate among risk-averse investors.

Those influenced by financial consultants or online sources show stronger interest in market-linked investments.

High positive correlation between Mutual Funds ↔ Equity Market, indicating similar investor mindset.

Negative correlation between Equity ↔ Fixed Deposits, showing risk-return contrast.
